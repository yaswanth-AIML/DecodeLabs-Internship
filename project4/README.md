# Image Text Recognition Using OCR

## Project Overview

This project was developed as part of the DecodeLabs Artificial Intelligence Internship.

The objective of this project is to recognize text from images using Optical Character Recognition (OCR). The application allows users to select an image, extracts the text using the Tesseract OCR engine, highlights the detected characters with bounding boxes, and displays the processed image.

---

## Features

- Select an image using a file dialog
- Detect text from images
- Recognize letters and numbers
- Draw bounding boxes around detected characters
- Display extracted text
- Display processed image with highlighted text
- Uses OpenCV for image processing
- Uses Tesseract OCR for text recognition

## Workflow

1. Select an image.
2. Read the selected image.
3. Convert the image into RGB format.
4. Perform OCR using Tesseract.
5. Extract text from the image.
6. Detect character locations.
7. Draw bounding boxes around recognized characters.
8. Display the processed image.
