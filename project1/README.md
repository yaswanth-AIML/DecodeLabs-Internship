# Rule-Based AI Chatbot

## Overview

This project is a simple Rule-Based AI Chatbot developed using Python as part of my internship tasks. The chatbot interacts with users by recognizing predefined commands and providing appropriate responses.

The project demonstrates fundamental concepts of Python programming, including functions, dictionaries, conditional statements, loops, and user input handling.

## Features

* User input sanitization using string methods.
* Rule-based response system.
* Predefined commands and chatbot replies.
* Help menu displaying available commands.
* Exit functionality using keywords such as `bye`, `exit`, and `quit`.
* Interactive command-line interface.

## Technologies Used

* Python 3

## Project Structure

* `sanitize()` – Cleans user input by removing extra spaces and converting text to lowercase.
* `responses` – Stores predefined questions and answers using a dictionary.
* `getresponse()` – Processes user queries and returns suitable responses.
* Main program loop – Handles chatbot interaction until the user exits.
