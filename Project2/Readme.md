# Breast Cancer Classification Using Machine Learning

## Project Overview

This project focuses on classifying breast cancer tumors as malignant or benign using machine learning classification algorithms.

The dataset was analyzed, preprocessed, and used to train multiple classification models. The performance of each model was evaluated using accuracy score, confusion matrix, and classification metrics.

## Dataset

Breast Cancer Wisconsin Dataset

Target Classes:

* Malignant (1)
* Benign (0)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Machine Learning Models

1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors (KNN)

## Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Data Visualization
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Comparison

## Evaluation Metrics
* Accuracy Score
* Confusion Matrix
## Results
The trained models were evaluated and compared based on their classification performance on the test dataset.
## Conclusion
Multiple machine learning classification algorithms were applied to the Breast Cancer dataset. Their performance was compared using standard evaluation metrics. This project demonstrates the practical implementation of supervised learning techniques for medical data classification.
