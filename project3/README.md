# DecodeLabs AI Internship - Project 3

## AI Recommendation System

### Project Overview

This project was developed as part of the DecodeLabs Artificial Intelligence Internship.

The objective of this project is to build a simple AI Recommendation System that suggests movies based on user interests and preferences. The system uses similarity-based recommendation logic to match user-selected genres with available movie genres and generates ranked recommendations.

### Features

* User-friendly command line interface
* Accepts multiple user interests
* Matches preferences with movie genres
* Calculates similarity scores
* Ranks recommendations based on matching interests
* Displays top recommendation
* Allows multiple recommendation searches

### Technologies Used

* Python

### Recommendation Logic

The system works by:

1. Taking user interests as input.
2. Comparing user interests with movie genres.
3. Calculating a similarity score for each movie.
4. Ranking movies based on the similarity score.
5. Displaying the best recommendations.

### Dataset

A predefined movie dataset containing:

* Movie Names
* Genre Categories

Genres Included:

* Action
* Sci-Fi
* Adventure
* Drama
* Thriller
* Horror
* Mystery
* Romance
* Crime
* Fantasy

### Example

Input:

Action, Sci-Fi

Output:

Avengers Endgame
Spider Man No Way Home
Interstellar
Doctor Strange
